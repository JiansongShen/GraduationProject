\subsection*{A.1 项目结构说明}
本项目采用模块化目录布局，便于维护、扩展与复现实验：
\begin{itemize}
\item \texttt{core/}：配置数据结构、YAML 加载与随机种子管理；
\item \texttt{data/}：医学影像补丁数据管线与风险表格数据处理；
\item \texttt{model/}：分割模型（\texttt{aneurysm}）与风险模型（\texttt{risk}）；
\item \texttt{script/}：训练、评估与对比实验入口脚本；
\item \texttt{ui/}：FastAPI 服务与推理接口封装；
\item \texttt{utils/}：日志、路径与通用工具函数。
\end{itemize}

\subsection*{A.3 分割任务复现实验步骤}
\begin{enumerate}
\item 准备 NIfTI 影像与标签数据，确保命名规则与配置文件一致；
\item 复制并修改配置文件（如 \texttt{config/host.yaml}），填写训练/验证路径；
\item 运行训练命令：\texttt{python script/train\_split.py --config path/to/your.yaml}；
\item 通过 TensorBoard 观察收敛曲线并记录最优检查点；
\item 运行评估脚本导出指标与可视化结果。
\end{enumerate}

\subsection*{A.4 风险预测复现实验步骤}
\begin{enumerate}
\item 准备包含标签列与病例 ID 的表格数据（Excel/CSV）；
\item 在配置中启用风险模块并设置特征与训练参数；
\item 运行训练命令：\texttt{python script/train\_risk.py --config path/to/your.yaml}；
\item 查看输出 \texttt{risk\_report.json} 并记录 F1、AUC 与最优阈值；
\item 可选运行 \texttt{compare\_risk\_models.py} 与传统模型进行统一对比。
\end{enumerate}

\subsection*{A.5 关键参数说明}
\begin{itemize}
\item 分割参数：\texttt{train.epochs}、\texttt{train.patch\_size}、\texttt{train.learning\_rate}、\texttt{eval\_interval}；
\item 风险参数：\texttt{risk.hidden\_dim}、\texttt{risk.num\_heads}、\texttt{risk.num\_layers}、\texttt{risk.threshold\_search\_steps}；
\item 数据参数：\texttt{data.patch\_sampling\_mode}、\texttt{risk.feature\_select\_method}。
\end{itemize}

\subsection*{A.6 常见问题与排查建议}
\begin{itemize}
\item \textbf{显存不足}：减小 \texttt{patch\_size} 或减少每例补丁数量；
\item \textbf{训练不收敛}：检查学习率、标签映射及数据归一化流程；
\item \textbf{指标异常波动}：固定随机种子并核查数据划分一致性；
\item \textbf{LaTeX 目录报错}：清理 \texttt{.aux/.toc/.out} 后重新编译。
\end{itemize}
