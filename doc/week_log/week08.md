# 第8周周记

**时间**：第8周  
**主题**：形态学特征与表格数据

本周学习基于分割掩膜的体积、表面积、球形度等形态学描述，理解其作为病例级特征输入风险模型的意义。并行整理临床与表型字段类型：连续变量、类别变量与缺失值策略，思考异构数据统一嵌入的必要性。

完成工作：调用 `extract_morphology_features` 流程对若干预测掩膜试算特征；检查特征量级与异常值；与 `build_risk_data_bundle` 输出字段对齐，确认 patient id 关联无错位。

**收获与问题**：分割误差会传递到下游特征，需在论文中讨论误差传播；表格长尾类别需统计频次再决定是否合并。下周深入风险模型与特征筛选。
