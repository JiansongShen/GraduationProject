# 第6周周记

**时间**：第6周  
**主题**：损失函数与优化策略

本周学习 Dice、Tversky、Focal 与 BCE 在极度不平衡分割中的互补关系：区域重叠型损失直接对齐病灶重叠度，Focal 降低易分类背景权重。对照项目配置，理解 AdamW、余弦退火等超参如何通过 YAML 统一管理，减少硬编码。

完成工作：在验证集上对比两组损失权重，记录 Dice 与 Hausdorff 相关指标变化趋势；固定随机种子复现一次短训，确认可重复性；整理超参表至实验章节草稿。

**收获与问题**：指标改善未必同步，需明确主指标（如病灶 Dice）与辅指标；过强前景损失可能带来假阳性，应结合可视化研判。下周进入整例推理与滑窗拼接。
