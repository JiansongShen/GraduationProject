# 第3周周记

**时间**：第3周  
**主题**：数据集与预处理约定

本周与导师确认训练与验证数据划分原则、伦理与脱敏要求，学习 NIfTI 等体数据格式的 spacing、origin、direction 含义。对照项目中的重采样与强度规范化流程，理解“统一空间与强度标尺”对跨病例泛化的作用。

完成工作：编写数据检查小脚本，统计病例体积尺寸分布与前景体素占比；验证读取路径与配置文件 `host.yaml` 中数据根目录一致；记录异常样本（运动伪影、金属伪影）并标注是否参与训练。

**收获与问题**：补丁训练必须在“上下文足够”与“显存可承受”之间折中；异常病例若不排除，会干扰损失曲线解读。下周进入 `MedicalPatchDataset` 与采样策略代码阅读。
