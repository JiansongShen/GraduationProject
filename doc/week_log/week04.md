# 第4周周记

**时间**：第4周  
**主题**：补丁数据集与采样策略

本周精读补丁数据集实现，理解前景优先采样与顺序采样的差异及适用场景。结合公式化风险表达，体会提高病灶邻域出现概率对缓解类别不平衡的意义，同时保留部分背景补丁以维持对正常解剖的判别边界。

完成工作：在小规模子集上跑通一个训练 epoch，确认 DataLoader 批量形状与标签对齐；调整 `batch_size` 与补丁尺寸试验点，记录 OOM 边界；开启 TensorBoard 记录损失与学习率曲线。

**收获与问题**：显存不足时优先减批量或补丁深度，其次再动网络宽度；日志命名需带配置标识以免混淆。下周聚焦分割网络前向与注意力门控模块。
