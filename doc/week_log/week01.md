# 第1周周记

**时间**：第1周  
**主题**：选题与任务书解读

本周在指导教师指导下确定毕业设计方向：基于深度学习的颅内动脉瘤 CTA 辅助分析，包含体素级分割与病例级破裂风险预测两个衔接子任务。我通读任务书，列出论文、程序与实验材料交付清单，并初步了解 DSA 与 CTA 在临床中的角色差异，以及 U-Net 类结构在医学分割中的常见用法。

完成工作：配置 Python、PyTorch 与 CUDA 环境，确认显卡驱动与版本匹配；克隆课题仓库，熟悉 `config` 与 `script` 目录职责；建立个人实验笔记目录，约定每周记录格式。

**收获与问题**：医学影像不仅要追求指标，还需面对体数据体积大、标注昂贵和临床可解释性等约束；对后续补丁训练与配置化流程有了心理预期。下周计划系统阅读开题与综述材料。
