1 绪论
1.1 研究背景与意义
我国居民死因构成中，脑血管疾病常年排在靠前位置，颅内动脉瘤也就是 In-
tracranial Aneurysm 即 IA，在无症状阶段时，往往会在影像学检查过程中被偶然发
现。瘤壁完整性一旦被破坏，就会造成蛛网膜下腔出血，病情通常比较凶险，遗留
神经功能障碍的比例也不容忽视。数字减影血管造影即 DSA 被当作诊断的“金标
准”来使用，但它属于有创检查，并且在费用方面也存在一定限制，因此较难在大
规模筛查场景中开展普及。CT 血管成像也就是 CT Angiography 即 CTA，具有无创
以及临床可及性较高的特性，在当前门诊以及急诊环境当中，是开展动脉瘤检出和
术前评估工作的重要工具 [1,2]
但是目前临床实际诊疗工作中还存在着三个比较突出的问题。第一，单次检
查所得到的切片数量最多可以达到几百层，医生要在大脑三维结构里追踪走形复
杂的血管脉络，还要去识别血管上的微小隆起，连续开展阅片工作后，容易出现视
觉疲劳，漏诊概率也会增加。第二，不同的扫描协议、重建层厚和对比剂充盈状态
不同，会导致最终生成的图像在对比度、颜色、层间距等参数上出现差异，同一套
算法在适配不同的数据来源和硬件设备时，很难保持稳定运行和可靠的泛化能力。
第三，临床是否需要开展干预工作，判断依据不只是存在动脉瘤这一核心事实，还
要结合瘤体大小、形态规则度、位置、患者年龄和合并症等各方面因素来综合考
虑；目前临床诊断过程中还会参照 PHASES、ELAPSS 以及日本 UCAS 等研究得出
的自然病程规律和风险评估标准 [3–6]。只有病灶分割掩膜和风险预测结果一起才能
完成完整的临床规划工作。
近些年来，依靠以多层神经网络为中心的深度学习技术，医学影像分割任务
已经有了较多的进展。全卷积网络以及 U-Net 族结构可以输出像素级的病灶概率
图，从而把临床医师进行标注辅助工作的时间缩短了 [7,8] ；三维卷积网络可以直接
对沿血管走向的上下文信息进行建模，同时对瘤体层间连续性等形态学特征的识
别也更加有利 [9,10] 。Attention U-Net 在解码路径中引入了注意力门控单元，可以引
导网络把重点放在任务相关的空间区域上，同时模型的分割表现也得到提高，相关
效果已经在腹部脏器、胰腺等分割任务中得到验证 [11] 。nnU-Net 的应用结果表明，
在做医学分割任务时，除了网络骨架之外，数据预处理、补丁采样、后处理等环节
都会对最终结果造成影响 [12]。在脑血管研究领域中，已经有工作把粗定位和细分
割结合起来使用，或者用多尺度三维卷积来提高细小病灶的检出率 [1,2,13] 。与此同
时，融合动脉瘤临床信息以及本体属性的风险预测网络也已经出现，这进一步说
明“影像 + 临床”的联合建模路径具有实际应用价值 [14,15] 。在表格数据学习领域

1.2 国内外研究现状
1.2.1 传统动脉瘤与脑血管影像分析的途径
在深度学习还没有大规模应用的时候，血管分割、病灶提取等任务基本都是
用传统的图像处理方法来完成的，常用的有基于强度的阈值分割、区域生长、水
平集方法，以及部分基于几何先验设计的滤波器。在这样的处理流程中，种子点、
平滑核大小、曲率约束等参数一般要人工去调整。同时该类方法对于低对比度瘤
颈、邻近骨质的高密度灶等干扰因素比较敏感，在面对不同的数据集时，还需要重
新做调参工作。风险评估环节中，临床诊断一般会使用 Hunt-Hess 分级、WFNS 评
分、PHASES 评分、ELAPSS 评分等规则体系，其中 PHASES 更重视未破裂动脉瘤
的后续破裂风险，ELAPSS 更关注肿瘤增长风险预测 [3,4] 。评分体系比较简洁，而
且有较强的可解释性，比较适合临床沟通；但是不能很好地捕捉瘤体形态不规则、
局部血管形态变化、影像纹理等非线性特征。统计学习阶段常用的逻辑回归、随机
森林等传统机器学习模型，可以给出可解释的结果，但是对多维关联特征的自动建
模能力还有待提高。
1.2.2 分割与多模态预测的深度学习实现
随着公开数据集和算力条件的不断改善，U-Net 以及三维变体已经逐渐成为血
管和病灶分割领域的主要网络骨架 [7,9] 。nnU-Net 相关的研究更重视预处理、网络
拓扑、后处理等环节的自动化配置工作，从而提高跨任务迁移的效率 [12] 。颅内动脉
瘤相关研究中，一种技术路径就是建立从血管分割到瘤体检测的多阶段处理流程，
另一种技术路径就是使用注意力和多尺度模块来加强细小结构识别的效果 [1,2]。在
预测研究中，Transformer 和注意力机制给序列化、多模态特征融合提供了一种比

1.3 本文面临的问题与主要思路
根据已有研究文献以及实际工程经验，本文将本次任务遇到的难点归纳为三
个方面。（1）体数据占用和显存的矛盾，单份完整的 CTA 数据体积可达数百兆字
节，如果一次性加载多组病例批次全部数据，普通 GPU 一般无法完成相应的运算
需求，因此需要在流式 IO、补丁采样、梯度更新等环节上进行调整。（2）前景极
度稀疏，动脉瘤对应的体素在整幅体积中所占的比例非常小，单独使用交叉熵损
失时，模型很容易把预测结果偏向背景，因此需要采用区域重叠型损失和采样策
略共同约束。（3）风险标签与特征的异质性，破裂和未破裂病例的样本分布不均，
类别字段中还存在着长尾取值，因此需要配合合理的加权损失、阈值搜索、特征筛
选步骤，来防止模型只学习到训练集分布而造成过拟合。
针对以上问题，本文提出了一种“分割骨干 + 表格风险头”的系统级方案。分
割模块使用三维 Attention U-Net，病例级流式训练和前景优先补丁采样一起做；风
险评估模块用基于交叉注意力的表格模型，对数值特征、类别特征做统一处理，在
验证集上做决策阈值搜索。

2.1 脑动脉瘤及分割基本原理
脑动脉瘤是指脑血管壁局部异常膨出后形成的囊状或者梭形结构，常见发生
位置为脑底部 Willis 环及其主要分支。CTA 图像上脑动脉瘤一般会显示为血管壁
局部的囊状突起，也就是“气球样”或者“浆果样”的异常膨出结构。
瘤颈即 neck，是指动脉瘤与载瘤动脉之间的连接部位，它的宽度以及形态对
临床诊断和治疗方案的选择有着重要的意义。

2.2 医学图像分割基本理论
医学图像分割是用像素或者体素来完成目标解剖结构的精确定位，属于密集
预测即 dense prediction 任务。与自然图像分割不同的是，CTA 体数据有三维空间
连续、前景占比很小、病灶形态差异大等特点。因此，模型不仅要对局部边缘和纹
理信息进行捕捉，还要保证跨层面的空间一致性。该研究范式已经在医学影像深
度学习综述中得到明确论证 [19–21] 。

2.3 卷积神经网络与 U-Net 结构
卷积神经网络即 CNN，依靠局部感受野、权值共享以及层级特征提取的方式，
可以较好地利用图像中层次化的特征，因此被广泛用于医学图像分析。对于分割任
务，Fully Convolutional Network 即 FCN 第一次把分类网络扩展到像素级预测，实
现端到端的密集输出 [8] 。U-Net 在此基础上采用对称的编码器-解码器结构和跳跃
连接即 skip connection，使浅层细节信息和深层语义信息得到融合，从而大大提高
医学图像分割的效果 [7] 。
由于三维医学图像在层间有很强的连续性，
 3D U-Net 把二维卷积替换成三维卷
积和三维上采样，可以同时得到切片内部和切片之间空间上下文信息 [9,22] 。V-Net、
UNet++、nnU-Net 等后续出现的模型对体素级残差建模、跳跃连接设计、自动化配
置等进行了改进，从而提高了医学图像分割性能 [10,12,23] 。但是三维卷积也会带来
更大的计算量和内存占用，因此实际应用中会采用补丁训练 (patch-based training)、
流式加载 (streaming loading)、混合精度训练 (mixed precision training) 等方式来减
轻资源的压力。
2.4 注意力机制与 Attention U-Net
注意力机制的核心就是使模型可以自动地把焦点放在与当前任务有关的区域
上。对于体积小、背景血管复杂的颅内动脉瘤分割任务，如果直接拼接所有的跳跃
连接特征，就会把大量的无关背景响应传送到解码器里，从而增加误分割的风险。
Attention U-Net 在跳跃连接处使用注意力门控即 Attention Gate 模块对编码器特征
进行筛选，使解码器更关注目标相关区域 [11] 。
从实现上讲，注意力门控会把解码器特征同尺度编码器特征融合映射成一张
空间权重图，再用这个权重图对编码器特征进行加权。本质上完成的是空间特征
的选择，即当某个位置更有可能是动脉瘤或者邻近血管的时候，该位置的权重就会

2.6 表格数据学习与特征表示理论
除了影像数据之外，临床信息、人口统计学特征、既往病史等一般会用结构化
表格的方式存储。传统的机器学习方法，逻辑回归、随机森林等，在特征维度低的
时候会有一定的优势，但是当遇到高维混合特征，即数值型和类别型特征同时存在
时，模型的表达能力就会受到很大的限制。
近些年来，深度表格学习开始借鉴 NLP 中的 Token 化思想，将每个特征字
段映射为统一维度的隐向量，再利用注意力机制来捕捉字段之间相互影响的关系。
TabTransformer 使用上下文化嵌入来增强类别变量的表达能力，FT-Transformer 则
证明了对数值字段进行 token 化并且使用 Transformer 编码的有效性 [16,17] 。不需要
人工创建高阶交叉特征，可以统一处理连续变量和离散变量，给多模态融合提供比
较灵活的表示方式。
本文风险预测模块就是按照这个思路来搭建的，同时研究中也保留了随机森
林和梯度提升树等传统的集成学习方法，作为小样本表格数据上的重要对比基
线 [27–29] 。

2.7 临床风险评分与深度模型的互补关系
未破裂颅内动脉瘤的管理不是单纯的图像分割问题。PHASES 评分把人群来
源、高血压、年龄、动脉瘤大小、既往蛛网膜下腔出血史、部位等作为影响因素来
估计未来的破裂风险 [3] ，ELAPSS 评分把年龄、部位、大小、形态、既往蛛网膜下
腔出血等因素纳入到未破裂动脉瘤增长风险预测中 [4] 。除此之外，大规模自然病程
队列研究也表明，不同部位、不同直径、不同形态不规则程度的动脉瘤，具有不同
的破裂倾向 [5,6] 。
上述评分体系有解释性强、使用门槛低的优点，但是它的变量项比较固定，很
难对三维分割衍生出的体积、表面不规则度、瘤颈宽度、影像组学纹理等高维信
息进行充分的提取。深度学习模型可以很好地在数据充足、划分严格的情况下学
习非线性交互。因此将注意力表示学习同传统的机器学习方法进行比较或者融合，
可以同时考察非线性表征能力以及小样本稳健性，并为风险预测提供更加全面的
方法学参照。
2.8 评价指标基础
分割任务常用 Dice 系数、敏感度即 Sensitivity、特异度即 Specificity、 Hausdorff
距离等指标，其中 Dice 系数主要用来衡量预测区域和真实区域之间的重叠程度。
分类和风险预测任务一般会用到准确率、精确率、召回率、F1 值和 AUC-ROC 等
指标。AUC 反映模型整体排序能力，F1 值则在不平衡场景下更能综合体现精确率
与召回率之间的平衡。由于医学管理系统中病灶漏诊的代价大于误诊，本文以召
回率为模型的重要评价指标，用 AUC 进行模型性能评价。
对于极度稀疏的医学分割任务，仅依靠总体准确率容易产生误导。因此，在实
验代码中同时给出 Dice 系数、体素级 F1、多阈值统计结果以及基于直方图近似的
voxel-wise AUC，从而对模型性能进行更加全面的评价；并且在不平衡二分类场景
下，PR 曲线和校准分析同样具有重要的参考价值 [30–33] 。

3.2 分割任务的理论基础与建模动机
颅内动脉瘤在 CTA 图像上一般会表现为体积小、边界不清、与邻近血管相互
黏连的异常膨出区，给分割任务带来明显的弱小目标、强背景干扰以及类别不平
衡等难题。
在此种情况下，仅仅依靠局部卷积感受野就会出现两个方面的问题，浅层特
征可以保留较多的空间细节，但是语义判别能力较弱，深层特征虽然有很强的抽
象表达能力，但是经过多次下采样之后，病灶的边界细节又会丢失。U-Net 类编码
器-解码器结构用跳跃连接较好地解决了这两方面的矛盾，因此成为三维医学图像
分割常用的框架。
但是标准 U-Net 对于复杂的血管背景仍然会引入很多和病灶无关的高响应区
域。因此本文在主干网络中加入注意力门控机制，用来抑制无关背景特征通过跳
跃连接的传播，在瓶颈层加入多尺度上下文增强模块和方向敏感注意力，从而更好
地捕捉病灶的尺度变化、形态不规则性和复杂的空间走向。本文的设计思想是病
灶分割不能只依靠局部灰度差异，而应该把局部边界、邻域血管拓扑关系、多尺度
上下文信息结合起来进行联合判断。

4.1 实验设计概述
本文实验以动脉瘤分割和破裂风险预测两个方面为研究对象，从体素级病灶

从分割任务的角度出发，对模型在训练后期的收敛稳定性、概率判别能力以及病

负担。F1 值是通过综合考虑 Precision 和 Recall 来给动脉瘤破裂风险预测的二分类

本文使用了两阶段的流程，虽然可以提高项目工程化水平和训练效率，但是分

割掩膜出现边界收缩、局部漏检或者误检的时候，体积、形态规则性等特征变量也
会随之发生偏移，从而对风险估计造成影响。目前还没有对这类误差传播进行系
统的建模，也没有对不同的分割质量水平对于风险预测的稳定性进行充分的评估。
因此，怎样量化上游结构识别的不确定性，怎样减少它对下游风险预测任务的影
响，依然是后续需要解决的问题。
