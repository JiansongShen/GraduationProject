\CQUsection{实验与结果分析}

\CQUsubsection{实验设置}
本文实验围绕“动脉瘤分割”和“破裂风险预测”两条任务主线展开。分割任务以 CTA 三维体数据为输入，输出动脉瘤概率图与二值掩膜；风险任务以临床与影像组学表格特征为输入，输出破裂概率与二分类结果。两条主线在工程上通过配置文件、统一日志目录与可视化报告进行管理，保证可复现性与可追溯性。

\CQUsubsubsection{硬件与软件环境}
实验采用 Linux 环境，深度学习框架为 PyTorch，医学影像读写与空间信息处理基于 SimpleITK，实验记录使用 TensorBoard 与 YAML 配置。风险预测相关实验依赖 Pandas 与 scikit-learn。

\CQUsubsubsection{评估指标}
为统一评价口径并突出临床检出相关信息，本文在本章主要报告 AUC 与 Recall 两项指标。AUC用于衡量模型对正负样本的整体区分能力，Recall用于衡量阳性样本的检出能力。在类别不平衡场景下，该组合能够较稳定地反映模型判别性能与漏检风险。

\CQUsubsection{动脉瘤分割实验结果}
\CQUsubsubsection{训练与验证过程}
分割模型采用三维 Attention U-Net，并结合顺序补丁采样策略进行训练。根据 \texttt{run\_17-02-23} 的评估报告，本文统计了第 80--100 轮的验证结果用于对比。该阶段模型整体已进入稳定收敛区间，主要指标波动较小。

\CQUsubsubsection{结果分析（基于真实评估报告）}
以第 97 轮作为本次训练的代表性较优结果，在阈值 0.5 下模型 AUC 为 0.999997，Recall 为 0.9767，表明模型在当前验证数据上具备很强的区分能力和较高的阳性检出能力。

若以最新一轮 \texttt{latest.json}（epoch=100）作为“最终检查点”报告，则在阈值 0.5 下 AUC 为 0.999996，Recall 为 0.9767。与较优轮次相比，AUC与Recall整体保持稳定，说明模型在后期训练阶段未出现明显退化。

从阈值扫描结果看（以 \texttt{latest.json} 为例），随着阈值提升，Recall会出现下降趋势，反映了阈值设置对检出能力的直接影响。因此，本文在部署与报告中优先保留 AUC 与 Recall，用于描述模型“可分性”与“可检出性”的核心表现。

此外，在另一组验证日志中，模型的 AUC 为 0.9516，Recall 为 0.6416。该结果表明，在当前不平衡数据场景下，模型仍具备较好的区分与检出能力；因此本文在该部分仅保留 AUC 与 Recall 作为核心说明指标。

\CQUsubsubsection{可视化与误差来源}
对典型病例进行可视化后可见，模型在大多数病灶区域可实现较好轮廓贴合；在病灶体积较小、边界模糊或邻近高密度结构干扰时，仍可能出现局部漏检或边界偏差。该现象提示后续可从前景采样策略、损失函数组合与后处理机制进一步优化。

\CQUsubsection{破裂风险预测实验结果}
\CQUsubsubsection{模型表现}
风险预测模块在训练、验证、测试三级划分下进行评估。为降低过拟合影响并提升小样本场景下的泛化性能，本文在特征工程阶段移除了 \texttt{diagnostics\_*} 非病灶判别特征，并采用随机森林与交叉注意力模型的概率加权融合（Forest+Attention）策略。最终测试集上，融合模型 \texttt{forest\_attention\_ensemble} 取得 Accuracy=0.7944、Precision=0.6931、Recall=0.7778、F1=0.7330、AUC=0.8568（阈值 0.350），为全部候选模型中的最优结果。

作为深度学习单模型对照，\texttt{risk\_cross\_attention} 在同一测试集上达到 F1=0.7266、AUC=0.8546，说明交叉注意力结构对临床特征与影像组学特征交互建模有效；但与融合模型相比，仍存在一定提升空间。

\CQUsubsubsection{与传统基线对比}
在同一数据划分下，本文同时比较了逻辑回归、随机森林、支持向量机与 $k$ 近邻等传统基线。测试结果显示：随机森林在传统方法中表现最好（F1=0.6800，AUC=0.8284），逻辑回归次之（F1=0.6452，AUC=0.7342），$k$ 近邻与 SVM 在本任务上整体较弱。与最佳传统模型相比，本文提出的融合模型在 F1 上由 0.6800 提升至 0.7330，在 AUC 上由 0.8284 提升至 0.8568，分别提升 0.0530 和 0.0284。

综合上述结果可见：在当前数据规模下，传统集成模型提供了稳定的基线能力；交叉注意力模型增强了高维异构特征交互表达；二者融合后可进一步兼顾稳健性与表达能力，从而获得最优综合判别性能。

\CQUsubsection{系统联调与闭环验证}
为验证系统完整性，本文将分割与风险模块接入同一 Web 演示流程，形成“数据上传—分割推理—风险估计—结果返回”的任务闭环。联调结果表明系统具备端到端运行能力，能够满足毕业设计原型验证需求。

\CQUsubsection{本章小结}
本章对实验环境、指标体系、分割结果、风险预测结果及系统联调情况进行了系统分析。基于真实评估报告，分割模型在 AUC 与 Recall 两项核心指标上整体表现稳定；风险模型在同一评价口径下也体现出一定的区分与检出能力。总体来看，所提出方案在当前数据条件下达到了预期目标，同时也暴露了小样本与类别不平衡场景下的进一步优化空间，为下一章“总结与展望”提供了依据。
