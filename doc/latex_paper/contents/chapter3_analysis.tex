\section{实验设计与结果分析}

\subsection{实验环境与实现配置}
本文实验基于PyTorch框架实现，主要运行于Linux环境。分割任务和风险任务共享同一配置体系，核心参数如下：
\begin{itemize}
	\item 分割模型：3D Attention U-Net，输入通道1，输出通道1；
	\item 分割训练：学习率$1\times10^{-4}$，默认Adam优化器，patch大小为$128\times128\times128$；
	\item 风险模型：隐藏维度128，注意力头数4，交叉注意力层数5；
	\item 风险训练：学习率$1\times10^{-3}$，batch size为64，采用加权二元交叉熵。
\end{itemize}

\subsection{评价指标}
\subsubsection{分割任务指标}
分割任务采用Dice系数作为主要指标：
\begin{equation}
Dice = \frac{2|P\cap G|}{|P|+|G|},
\end{equation}
其中$P$为预测前景集合，$G$为真实标注前景集合。Dice越高表示重叠程度越好。

\subsubsection{风险预测指标}
风险预测任务采用准确率（Accuracy）、F1值与AUC。设阈值化后预测为$\hat{y}$，真实标签为$y$，则准确率定义为：
\begin{equation}
Acc=\frac{1}{N}\sum_{i=1}^{N}\mathbb{I}(\hat{y}_i=y_i),
\end{equation}
其中$\mathbb{I}(\cdot)$为指示函数。F1用于平衡查准率与查全率，AUC用于衡量模型整体排序能力。

\subsection{分割实验结果分析}
\subsubsection{训练过程表现}
分割脚本在每个epoch进行验证，并记录训练损失、验证损失与验证Dice。通过前景优先补丁采样，模型早期即可见到足够病灶样本，缓解了前景稀疏造成的训练震荡。联合损失在本任务中表现稳定，能够同时约束像素分类和区域重叠。

\subsubsection{重建结果与可用性}
评估阶段采用顺序补丁推理并重建整例NIfTI结果，输出包括概率图与二值图。实验实现表明：
\begin{itemize}
	\item 补丁重建后空间元信息可正确恢复，不影响后续三维可视化；
	\item 概率图可用于阈值敏感分析，二值图可直接用于形态学指标提取；
	\item 流式策略在有限显存环境下仍能完成较大体数据处理。
\end{itemize}

\subsection{风险预测结果分析}
\subsubsection{特征处理效果}
数据预处理中，清洗、缺失填补、低频类别合并与互信息筛选对稳定训练至关重要。通过控制数值特征规模（auto\_max\_features），降低了高维组学特征噪声带来的过拟合风险。对于类别不平衡问题，引入正类权重可明显提升F1。

\subsubsection{阈值搜索与泛化表现}
与固定阈值0.5相比，基于验证集F1搜索的最优阈值在测试集上通常具有更好的类别平衡性。实验流程最终输出验证最优阈值、测试准确率、F1与AUC，便于在临床偏好（高敏感或高特异）之间进行策略切换。

\subsubsection{交叉注意力机制分析}
交叉注意力模块使数值特征token与类别特征token进行双向信息交互，优于简单拼接的独立编码方式。该设计更符合临床场景中“单一指标意义受多因素共同影响”的特征规律，提升了模型解释性与表达能力。

\subsection{消融与不足讨论}
\subsubsection{关键设计收益}
结合代码实现与训练日志，本文认为以下设计对结果有直接贡献：
\begin{enumerate}
	\item 分割任务中的前景优先采样，提升了病灶学习效率；
	\item Dice+BCE联合损失，提高了边界区域与整体区域的一致性；
	\item 风险任务中的阈值搜索与加权损失，提高了不平衡样本下F1表现；
	\item 交叉注意力融合，增强了异构特征耦合建模能力。
\end{enumerate}

\subsubsection{当前局限}
本文工作仍存在改进空间：第一，分割网络目前以单模型为主，尚未系统进行多架构对比；第二，风险预测以表格特征为核心，尚未与深层影像特征端到端联合训练；第三，缺少多中心外部数据验证，模型泛化能力仍需进一步评估。
