\CQUsection{绪论}

\CQUsubsection{研究背景与意义}

我国居民死因构成中，脑血管疾病常年排在靠前位置，颅内动脉瘤也就是Intracranial Aneurysm即IA，在无症状阶段时，往往会在影像学检查过程中被偶然发现。瘤壁完整性一旦被破坏，就可能造成蛛网膜下腔出血，病情通常比较凶险，遗留神经功能障碍的比例也不容忽视。数字减影血管造影即DSA被当作诊断的“金标准”来使用，但它属于有创检查，并且在费用方面也存在一定限制，因此较难在大规模筛查场景中开展普及。CT血管成像也就是CT Angiography即CTA，具有无创以及临床可及性较高的特性，在当前门诊以及急诊环境当中，是开展动脉瘤检出和术前评估工作的重要工具\cite{li2018coarse,chen2022coarse}。近年来，深度学习方法在医学影像分析中的应用不断增多，相关综述和代表性工作表明，U-Net、3D U-Net、Attention U-Net 和 nnU-Net 等结构已经成为医学图像分割任务中的重要基础模型\cite{litjens2017survey,shen2017deep,unet,unet3d,attention_unet,nnunet}。其中，分割任务的核心目标是准确识别CTA中的动脉瘤位置和边界，为后续定量分析提供可靠的空间掩膜。由于动脉瘤体积通常较小，且与周围血管、骨结构和噪声背景相互交织，分割模型既需要足够大的三维感受野来捕捉上下文信息，也需要保持较高的空间分辨率来恢复病灶边界，这也是三维卷积、注意力门控和多尺度特征融合广泛应用于该任务的重要原因。

与此同时，动脉瘤研究并不只停留在“是否存在病灶”的层面，更重要的是进一步评估其破裂风险。临床是否需要开展干预工作，判断依据不只是存在动脉瘤这一核心事实，还要结合瘤体大小、形态规则度、位置、患者年龄和合并症等各方面因素来综合考虑；目前临床诊断过程中还会参照PHASES以及日本UCAS等研究得出的自然病程规律和风险评估标准\cite{greving2014,morita2012}。因此，破裂风险预测任务的目标是将影像分割结果、病灶形态特征以及病例层面的临床信息联合起来，建立病例级风险判断模型。该类模型不仅需要处理影像数据中的空间结构信息，还需要融合表格数据中的异构变量，从而学习动脉瘤形态、临床背景与破裂结局之间的复杂关联关系。只有病灶分割掩膜和风险预测结果一起才能完成完整的临床规划工作。

近些年来，依靠以多层神经网络为中心的深度学习技术，医学影像分割任务已经有了较多的进展。全卷积网络以及U-Net族结构可以输出像素级的病灶概率图，从而把临床医师进行标注辅助工作的时间缩短了\cite{unet,long2015}；三维卷积网络可以直接对沿血管走向的上下文信息进行建模，同时对瘤体层间连续性等形态学特征的识别也更加有利\cite{unet3d,milletari2016}。Attention U-Net在解码路径中引入了注意力门控单元，可以引导网络把重点放在任务相关的空间区域上，同时模型的分割表现也得到提高，相关效果已经在腹部脏器、胰腺等分割任务中得到验证\cite{attention_unet}。nnU-Net的应用结果表明，在做医学分割任务时，除了网络骨架之外，数据预处理、补丁采样、后处理等环节都会对最终结果造成影响\cite{nnunet}。在脑血管研究领域中，已经有工作把粗定位和细分割结合起来使用，或者用多尺度三维卷积来提高细小病灶的检出率\cite{kamnitsas2017,li2018coarse,chen2022coarse}。与此同时，融合动脉瘤临床信息以及本体属性的风险预测网络也已经出现，这进一步说明“影像+临床”的联合建模路径具有实际应用价值\cite{strokenet,xiong2025}。在表格数据学习领域当中，注意力机制也被广泛用于多维临床字段之间的交互建模，这给本项目风险预测模块的设计提供参考。

根据以上背景，本文就动脉瘤自动分割定位和破裂风险概率预测这两个相互衔接的子问题，创建出一套以配置文件为驱动、可以利用脚本进行复现的软件系统。一方面可以减轻医师处理体数据时重复勾画的工作量，另一方面也为后续融合影像组学特征、形态学参数和表型数据预留了工程接口，有比较明确的辅助诊疗价值，也为整合医学影像和临床信息的医学软件系统提供了一套完整的方案。

\CQUsubsection{国内外研究现状}

\CQUsubsubsection{传统动脉瘤与脑血管影像分析的途径}

在深度学习还没有大规模应用的时候，血管分割、病灶提取等任务基本都是用传统的图像处理方法来完成的，常用的有基于强度的阈值分割、区域生长、水平集方法，以及部分基于几何先验设计的滤波器。在这样的处理流程中，种子点、平滑核大小、曲率约束等参数一般要人工去调整。同时该类方法对于低对比度瘤颈、邻近骨质的高密度灶等干扰因素比较敏感，在面对不同的数据集时，还需要重新做调参工作。风险评估环节中，临床诊断一般会使用Hunt-Hess分级、WFNS评分、PHASES评分等规则体系，其中PHASES更重视未破裂动脉瘤的后续破裂风险\cite{greving2014}。评分体系比较简洁，而且有较强的可解释性，比较适合临床沟通；但是不能很好地捕捉瘤体形态不规则、局部血管形态变化、影像纹理等非线性特征。统计学习阶段常用的逻辑回归、随机森林等传统机器学习模型，可以给出可解释的结果，但是对多维关联特征的自动建模能力还有待提高。

\CQUsubsubsection{分割与多模态预测的深度学习实现}

随着公开数据集和算力条件的不断改善，U-Net以及三维变体已经逐渐成为血管和病灶分割领域的主要网络骨架\cite{unet,unet3d}。nnU-Net相关的研究更重视预处理、网络拓扑、后处理等环节的自动化配置工作，从而提高跨任务迁移的效率\cite{nnunet}。颅内动脉瘤相关研究中，一种技术路径就是建立从血管分割到瘤体检测的多阶段处理流程，另一种技术路径就是使用注意力和多尺度模块来加强细小结构识别的效果\cite{li2018coarse,chen2022coarse}。同时也有使用超分辨率进行数据预处理优化模型分割效果的实现\cite{He2026Increased}，有效降低了cta模糊带来的效果降低的影响。在预测研究中，Transformer和注意力机制给序列化、多模态特征融合提供了一种比较标准的实现方式\cite{vaswani2017}，像StrokeNet这样的多任务结构可以对影像信息和临床信息进行编码，最后得到卒中结局的预测结果\cite{strokenet}。这些研究结果共同表明，分割精度和下游临床推理并不是彼此割裂的，高质量掩膜既可以用于手术规划，也可以把形态学等衍生特征当作载体来使用。

\CQUsubsubsection{当前研究仍然存在的不足之处}

当前的部分研究仍主要集中在单一的任务部分，比如单独对动脉瘤或者对象进行分割\cite{long2015,milletari2016,nnunet,Zeng2026AI}。其虽取得了较好的效果，却并未使用动脉瘤的分割结果与形态学特征进行后续的处理以生成完整的临床风险预测参考，这导致了模型仅能分割动脉瘤却无法继续为医师生成较为完善的可供参考的临床诊断。同时Ishikawa\cite{Ishikawa2026Detection}的工作虽然进行了动脉瘤分割，但是在后续的处理中单独使用UCAS的报告结果，并未充分利用现有的结果。亦有完善了二阶段任务，但仍然需要人手工对特征处理\cite{Ali2026ijasis}的缺点。其部分虽然取得了较好的预测效果，但是在数据变更或出现不同数据条件时，人手工往往难以快速完成特征转换。

\CQUsubsection{本文面临的问题与主要思路}

根据已有研究文献以及实际工程经验，本文将本次任务遇到的难点归纳为三个方面。（1）体数据占用和显存的矛盾，单份完整的CTA数据体积可达数百兆字节，如果一次性加载多组病例批次全部数据，普通GPU一般无法完成相应的运算需求，因此需要在流式IO、补丁采样、梯度更新等环节上进行调整。（2）前景极度稀疏，动脉瘤对应的体素在整幅体积中所占的比例非常小，单独使用交叉熵损失时，模型很容易把预测结果偏向背景，因此需要采用区域重叠型损失和采样策略共同约束。（3）风险标签与特征的异质性，破裂和未破裂病例的样本分布不均，类别字段中还存在着长尾取值，因此需要配合合理的加权损失、阈值搜索、特征筛选步骤，来防止模型只学习到训练集分布而造成过拟合。

针对以上问题，本文提出了一种“分割骨干+表格风险预测”的系统级方案。分割模块使用三维Attention U-Net，病例级流式训练和前景优先补丁采样一起做；风险评估模块用基于交叉注意力的表格模型，对数值特征、类别特征做统一处理，在验证集上做决策阈值搜索。

\CQUsubsection{课题来源与研究内容}

本课题来源于指导教师下发的毕业设计任务书，研究的主要任务有两个，一是对颅内动脉瘤的CTA数据进行计算机辅助检测，二是利用临床表型和影像衍生特征来实现破裂风险的二分类预测。本文具体工作为：

\begin{enumerate}
\item 用\texttt{AttentionUnet}搭建三维分割网络的编码器—解码器通道配置、注意力门控和带sigmoid输出的端到端前向传播全过程；
\item 在\texttt{MedicalPatchDataset}上做多目录数据扫描、重采样和标准化工作，设置前景优先和顺序采样两种可选策略，支持低显存条件下的长时间训练；
\item 使用配置化的优化流程，对Dice/ Tversky/ Focal和BCE的组合损失、Adam/ AdamW/ SGD优化器和余弦退火策略进行统一的管理，把训练过程写入TensorBoard，按设定的间隔保存最新的模型和验证集最优模型；
\item 推理阶段将补丁结果拼接成完整的体积，对spacing、origin、direction进行恢复，输出概率体和二值掩膜，便于之后做可视化或者形态学特征提取；
\item 完成表格风险数据清洗、互信息特征筛选、加权BCE训练、验证集F1最优阈值搜索、测试集报告导出等流程构建；
\item 搭建一套基于FastAPI的交互界面，用于开展文件上传、分割、风险预测等流程。
\end{enumerate}

\CQUsubsection{论文结构安排}

本文共分为五章。第一章主要对研究背景、国内外研究现状、当前问题难点以及本文的核心内容进行阐述。第二章对医学图像分割、三维卷积网络、注意力机制、类别不平衡学习、表格建模等方向的理论基础进行整理。第三章以系统整体架构为研究对象，分别对分割模块和风险模块的模型设计思路和实现要点进行说明，并简要介绍Web服务接口。第四章列出实验运行环境、数据集及预处理规则、评价指标和结果分析框架，说明如何依靠日志和配置文件复现相关指标。第五章对全文进行总结，并对后续可行改进方向进行展望。

\CQUsubsection{本章小结}

本章主要从颅内动脉瘤辅助分析研究动机出发，从临床实际需求和现有技术发展趋势两个方面进行了说明，对传统的和深度学习的方法进行了比较，总结出本文要解决的三个主要问题以及相应的思路，对应该与源代码模块相对应的研究内容做了列举。之后还会继续对算法以及系统实现做更多的展开。
