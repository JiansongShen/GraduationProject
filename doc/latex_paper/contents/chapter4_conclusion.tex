\CQUsection{结论与展望}

\CQUsubsection{工作总结}
本文面向毕业设计任务书中“颅内动脉瘤 CTA 的计算机辅助检测与破裂风险预测”的综合要求，在约一个学期周期内完成了\textbf{算法调研—工程实现—实验验证—系统集成}的完整链条。与班级内常见的单一分类或分割课题相比，本文的实际工作量体现在两类异构数据（体素张量与表格行）的\textbf{并行建模}，以及二者在演示层面的\textbf{可选串联}。下文按任务维度归纳具体成果，避免仅罗列文件夹名称而缺少学术表述。

\CQUsubsubsection{分割子任务：从数据协议到可交付模型}
在数据层，本文基于 \texttt{MedicalPatchDataset} 落实了多根目录扫描、影像—标签后缀匹配、体素间距重采样与强度标准化，并针对 CTA 前景极度稀疏的特点采用前景优先补丁采样与背景补丁配比策略；在模型层，采用三维 Attention U-Net，使解码端每个尺度上的跳跃连接在拼接前经过注意力门控滤波，减轻宽阔血管背景对梯度学习的干扰；在优化层，采用二元交叉熵与 Dice 损失的联合目标，并在验证集 Dice 最优准则下维护 \texttt{best.pth} 检查点；在推理层，采用顺序补丁遍历与体积拼接，利用 SimpleITK 恢复 NIfTI 的几何元数据，保证输出可与原始 CTA 在同一坐标系下叠加显示。上述环节均有对应脚本与配置项，形成了可写入毕业论文附录的\textbf{可复现流程说明}。

\CQUsubsubsection{风险子任务：从表格清洗到阈值固定的决策规则}
在数据层，风险管线支持缺失值处理、低频类别合并、互信息特征筛选及训练/验证/测试划分；在模型层，\texttt{RiskCrossAttentionModel} 将数值与类别字段映射为 token，经多层双向交叉注意力后再融合预测破裂概率，相比“手工拼特征 + 浅层分类器”更能表达异构字段之间的交互；在训练层，采用加权二元交叉熵缓解类别不平衡，并在验证集上对决策阈值做网格搜索以优化 F1；在产出层，模型权重与 \texttt{risk\_report.json} 一并保存，便于答辩时展示 JSON 中的 AUC、F1 与最优阈值。该子任务与分割子任务相对独立，符合临床“先勾画、再统计风险因子”的思维顺序，又便于分工调试。

\CQUsubsubsection{工程集成与演示}
本文在 \texttt{train\_split.py}、\texttt{train\_risk.py} 两个入口上统一了 YAML 配置、日志与随机种子策略；提供 TensorBoard 曲线与检查点文件支撑实验章节插图；在 \texttt{ui/main.py} 中提供 FastAPI 服务，用于上传 CTA、触发补丁推理及表格风险推断，支撑毕业答辩中的\textbf{现场演示}。从软件工程角度，这种“配置驱动 + 脚本入口 + 可选 UI”的结构降低了后续迁移到院内服务器或容器化部署的改造成本。

\CQUsubsubsection{与参考范式的对照}
参考论文以二维显微图像分类为主线，强调频域模块与多尺度骨干网络；本文任务为三维分割与表格二分类，技术难点集中在\textbf{体数据 IO 与显存约束}、\textbf{类别不平衡下的决策阈值}以及\textbf{异构特征融合}。因工作侧重点不同，本文未强行套用频域模块，而是在第二章中如实撰写与本项目代码一致的结构与损失，并在第三章用较大篇幅展开实验设计与结果解读框架——对应评委对“工作量是否饱满”的常见问题。

\CQUsubsection{主要特点与创新点归纳（本科论文尺度）}
在不夸大学术创新的前提下，可将本文特点概括为以下几点：
\begin{itemize}
	\item \textbf{任务贴合临床链条}：同时覆盖“瘤体在哪里”的像素级定位与“风险高不高”的个体级预测，体现卒中专病场景下的完整辅助诊断闭环雏形。
	\item \textbf{工程与算法并重}：不仅实现网络前向，还落实病例流式训练、整例几何一致性、风险 JSON 报告等\textbf{可交付细节}，避免停留在 Jupyter  notebook 级别的原型。
	\item \textbf{实验章节可扩展}：第3章已为分层统计、泄漏防护、消融与灵敏度分析预留书写框架，便于在补充实验数据后直接落地为图表。
\end{itemize}

\CQUsubsection{不足与展望}
\CQUsubsubsection{数据与评测层面}
当前工作流主要面向课题组本地数据形态；未来应在\textbf{多中心数据}上开展外部验证，报告 DSC、HD、AUC 的置信区间，并记录不同机型、对比剂方案、重建核函数对算法的干扰。对于分割金标准，建议逐步过渡到\textbf{多人标注 + 仲裁}机制，并在论文中报告标注一致性系数。

\CQUsubsubsection{算法与建模层面}
分割网络仍可探索：轻量级深度可分离卷积、nnU-Net 风格自动配置、基于 Transformer 的长程依赖建模；风险模型可引入\textbf{概率校准}（温度缩放、Platt scaling）与\textbf{代价敏感学习}，使阈值选择不仅依赖 F1，还能接入临床效用函数。更进一步，可将分割输出经形态学特征提取后作为表格字段的\textbf{不确定输入}，研究分割误差向风险预测的传递规律。

\CQUsubsubsection{系统与合规层面}
Web 演示模块当前侧重功能闭环；若要进入院内试点，需要补齐用户鉴权、审计日志、患者隐私脱敏与推理耗时优化（模型蒸馏、TensorRT、分布式推理）。任何面向诊疗决策的输出，都应纳入伦理审查与医疗器械监管路径评估，本文原型不等于医疗器械产品。

\CQUsubsubsection{个人收获与后续学习计划}
通过本课题，作者系统性实践了医学影像深度学习项目的\textbf{需求分解—模块实现—实验记录—论文撰写}流程，熟悉了 PyTorch 训练循环、SimpleITK 几何处理与表格建模的基本套路。后续计划在硕士或入职阶段继续补齐统计学与因果推断基础，尝试将辅助诊断系统的评价指标与真实临床结局队列对齐。

\CQUsubsection{结束语}
本文实现了一套面向颅内动脉瘤的辅助分析原型系统：分割分支提供可叠加于 CTA 的三维概率与掩膜输出，风险分支在表格数据上给出可阈值化的破裂概率，并以配置文件与脚本保证了基本的可复现性。受本科毕业设计周期与数据获取条件限制，部分数值实验仍需在后续工作中补全；但就已完成的代码结构与第3章所搭建的实验分析框架而言，已为\textbf{继续填充真实数据、替换示例表格、形成最终答辩定稿}预留了明确接口。
