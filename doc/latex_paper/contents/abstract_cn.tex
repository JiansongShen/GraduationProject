颅内动脉瘤是常见的脑血管异常，一旦破裂可引发蛛网膜下腔出血，致死率与致残率均较高。CTA 能在术前较清晰地显示载瘤血管与瘤体形态，但完整序列切片数量多、血管分叉及骨伪影复杂，医生在长时间读片下仍可能出现漏检或意见分歧。与此同时，破裂风险受年龄、基础病、瘤体形态与位置等多源异质信息共同影响，传统量表或单一统计模型难以同时刻画连续变量与类别变量之间的非线性交互。因此，研究“从血管影像中稳定勾画动脉瘤，并结合临床表型进行风险分层”的计算机辅助方法，对提高筛查效率与促进诊疗规范化具有现实意义。\par

针对上述需求，本文在毕业设计阶段实现并串联了两条可复现的技术路线。第一，在分割子任务中采用三维 Attention U-Net：编码器—解码器结构保留 U-Net 的多尺度跳跃融合能力，在解码端每个上采样阶段引入注意力门控，对来自编码器的跳跃特征进行加权抑制，使网络在背景体素占比较高的 CTA 体积中更关注疑似瘤颈与瘤体区域；训练侧采用病例级流式加载与三维补丁采样，配合体素间距重采样与强度标准化，在有限显存条件下完成大规模体数据的迭代优化；损失函数由二元交叉熵与 Dice 损失加权组合，以兼顾逐体素分类概率与区域重叠度。推理阶段对整例体数据按顺序切块前向，再将补丁预测结果拼接还原，并写回与原始影像一致的坐标系信息，便于与放射工作站或后续组学流程对接。\par

第二，在破裂风险预测子任务中，面向表格型临床与影像衍生特征，构建了数值通道与类别通道分离编码的 RiskCrossAttentionModel：连续特征经可学习的尺度因子与偏置映射为特征维上的 token，离散特征经嵌入层映射到同一隐空间；多层交叉注意力块在两路 token 之间交替更新表示，最后对两路池化向量拼接后经多层感知机输出破裂概率。数据管线集成缺失值填补、低频类别合并、基于互信息的特征筛选以及训练集上的类别频次加权损失；验证集上执行阈值网格搜索以最大化 F1，并将最优阈值固定在测试评估阶段，从而缓解类别不平衡带来的默认 0.5 切分失真问题。\par

工程层面，上述模块通过 YAML 统一配置，训练脚本 \texttt{train\_split.py} 与 \texttt{train\_risk.py} 分别输出分割检查点与 \texttt{risk\_report.json} 等指标摘要；系统还提供基于 FastAPI 的简易交互界面，支持上传体数据、触发补丁推理及表格风险预测，形成“分割—特征—风险”闭环演示流程。需要说明的是，受医院数据脱敏与伦理审批进度影响，本文在摘要层面侧重方法论与系统架构叙述；具体量化指标应以读者在本地复现实验后获得的验证/测试集评价为准。\par
